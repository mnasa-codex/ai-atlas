# تطوير واجهة أطلس

## النطاق

هوية فضائية ذهبية ضمن `.atlas-public` فقط، مع الحفاظ على Cairo وإضافة Space Grotesk للمحتوى التقني. الملفات الوظيفية `lib/tools.ts` و`data/catalog.json` و`app/admin/page.tsx` و`components/AdminEditor.tsx` ومنطق البحث والتصفية والأسعار لم تتغيّر. إعدادات التصدير وGitHub Pages الحالية محفوظة.

## الحركة وإتاحة الاستخدام

- تظهر الواجهة والمحتوى الأساسيان من HTML دون انتظار المشهد الثلاثي الأبعاد.
- تُحمّل الكرة والنجوم عبر `next/dynamic` بعد السماح بالحركة وظهور المشهد، مع بديل ثابت عند تعذّر WebGL.
- يتوقف رسم الكرة عندما تخرج من نطاق العرض أو يُخفى التبويب؛ وتتوقف النجوم عند إخفائه.
- يُتابع `prefers-reduced-motion` أثناء التصفح. زر «إيقاف الحركة» يوقف المؤثرات، ويُحفظ الاختيار في جلسة التبويب فقط.
- «هالة أطلس» مرتبطة ببداية أول تحوّل للكرة، وتُعرض مرة في جلسة التبويب. التخزين يحتوي تفضيل الحركة وعلامة العرض فقط، ولا يمثل بيانات نشاط.
- نبضة الشعار زخرفية، ولا تدّعي اتصالًا أو معالجة أو نشاط مستخدمين.
- ظهور الأقسام عند التمرير لا يخفي HTML الأصلي ولا يؤخر نتائج البحث.
- مناطق الـAccordion مربوطة بأزرارها عبر ARIA؛ المحتوى المطوي `inert`، والإغلاق يعيد التركيز إلى العنصر السابق.

## التحقق

```bash
npm ci
npm test
NEXT_PUBLIC_BASE_PATH=/ai-atlas npm run build
npm run typecheck
node tests/static.cjs
```

سير `Atlas UI checks` يبني النسخة ويختبرها عند فتح طلب الدمج، ويرفق `atlas-ui-preview`. لا ينشر الموقع ولا يعدل `main`. يستمر النشر الحالي بعد الدمج إلى `main` فقط.

اختبارات الصياغة والعقود البرمجية ليست بديلًا عن فحص المتصفح أو اختبار الأداء على جهاز فعلي. نتائج تنفيذ هذه الجولة موثقة في ملف التسليم، وليست مفترضة من وجود سير الاختبار.

## فحص المتصفح

راجع العرض عند 390 و768 و1440 بكسل، البحث والتصفية والترتيب، التنقل بلوحة المفاتيح، المودال وEscape وإعادة التركيز، تغيير تفضيل الحركة أثناء التصفح، زر إيقاف الحركة، الرجوع إلى الصفحة دون إعادة الهالة، فشل WebGL، وخلو الصفحات من التمرير الأفقي.

الخطوط محمّلة عبر Google Fonts باستخدام `display=swap` مع بدائل نظامية؛ لم تُرفق ملفات خطوط.
