مولّد صفحات الأدوات

اكتب اسم الأداة فقط. المحتوى يُولَّد كمسوّدة، والأسعار لا تُلمَس آلياً — تُدخلها أنت يدوياً.

خطوتك بعد التوليد

١. افتح content/<slug>.json وأدخِل الأسعار الحقيقية في pricing.plans[].price واضبط contact_for_price على false لكل خطة لها سعر رقمي.
٢. لخطة بلا سعر معلن: اتركها amount: null وcontact_for_price: true فتظهر كتلة واتساب تلقائياً.
٣. اضبط pricing.verify_required: false بعد المراجعة لإخفاء بانر التحذير.
٤. اضبط meta.status: "published" ثم npm run build.
