# أطلس — منصة اكتشاف أدوات الذكاء الاصطناعي

واجهة عربية RTL مبنية على Next.js وReact وTypeScript. هوية كحلية مع بنفسجي ونعناعي، مكتبة قابلة للبحث والتصنيف، ومقارنة خطط مع تفاصيل وروابط رسمية.

## التشغيل والتحديث

```bash
npm ci
npm run dev
```

استخدم /admin محليًا لتحرير المحتوى، ثم صدّر catalog.json واستبدل data/catalog.json. الحفظ المحلي يحفظ المسودة على المتصفح فقط. ارفع الملف إلى main لتبدأ عملية GitHub Pages الموجودة في .github/workflows/deploy-pages.yml.

```bash
npm test
NEXT_PUBLIC_BASE_PATH=/ai-atlas npm run build
node tests/static.cjs
```

الموقع نسخة ثابتة بلا خادم كتابة أو قاعدة بيانات. محرر المحتوى محلي فقط وغير مُصدّر للإنتاج. بحث الشعارات محلي من قائمة الأدوات ولا يحتاج API. لا تستخدم npm start لهذه النسخة: انشر محتويات out على الاستضافة الثابتة، كما يفعل سير العمل الحالي.

## الوظائف

بحث عربي وتصنيفات وفلاتر وترتيب، مقارنة الخطط شهريًا وسنويًا، نافذة تفاصيل تدعم Escape وحصر التركيز، وروابط التواصل الأصلية. تشترك الصفحات كلها في data/catalog.json، ويمنع التحقق من المحتوى بناء بيانات غير صالحة.

## الحماية وحدودها

- Next.js 15.5.25 وPostCSS 8.5.28 مع ملف قفل مثبت.
- بيانات المحتوى متحققة عند البناء والتصدير: HTTPS، أسعار غير سالبة، وحدود حجم وتكرار.
- لا يوجد مسار كتابة أو محرر منشور. عضوية المسؤولين محمية بـRLS في مخطط Supabase الاختياري غير المتصل بالنسخة الحالية.
- سياسة CSP أساسية داخل HTML وسياسة إحالة. GitHub Pages لا ينفّذ ترويسات Next.js المخصصة؛ لا تدّعي هذه النسخة توفير X-Frame-Options أو frame-ancestors من التطبيق. يمكن توفيرهما عبر استضافة تسمح بترويسات مخصصة إذا احتجت ذلك.
- أسعار ومزايا الأدوات موروثة من الملف الأصلي ولم يتم التحقق منها حديثًا. راجع المصدر الرسمي قبل الاشتراك.
- بيانات التواصل محفوظة في demoSettings داخل lib/tools.ts.
- لم يُجر اختبار اختراق أو اختبار متصفح بصري أو اختبار SQL على قاعدة حية. نجاح npm audit ليس ضمانًا ضد جميع الثغرات.
