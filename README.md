# أطلس — Atlas AI Directory

منصة عربية احترافية لدليل أدوات الذكاء الاصطناعي، مبنية على Next.js + React + Tailwind + Framer Motion، مع أساس جاهز للربط بـ Supabase.

## تشغيل محلي
```bash
npm install
npm run dev
```
ثم افتح `http://localhost:3000`.

## الصفحات
- `/` الرئيسية
- `/tools` مستكشف الأدوات
- `/pricing` مقارنة الأسعار
- `/contact` التواصل
- `/admin` لوحة إدارة معاينة محلية

## Supabase للإنتاج
1. أنشئ مشروع Supabase.
2. نفّذ `supabase/schema.sql`.
3. أنشئ مستخدم Admin في Auth ثم أضف UUID الخاص به إلى `admin_users`.
4. انسخ `.env.example` إلى `.env.local` وأضف المفاتيح.

> الأسعار الموجودة في النسخة الحالية بيانات محدَّثة يدويًا وقت الكتابة (سبتمبر 2026) مع رابط ومصدر لكل خطة، لكنها تتغيّر بوتيرة سريعة عند بعض الشركات (Google، GitHub تحديدًا) — راجعها من المصدر الرسمي دوريًا وحدّث حقل "آخر تحقق" من لوحة التحكم.

## إضافات هذا الإصدار

**1. تفاصيل أوضح للخطط عند الضغط** — كل خطة بصفحة الأداة صارت قابلة للطي/الفتح (Accordion): تعرض لمن تناسب، التطبيقات المرفقة ضمنها (مثل Flow وNotebookLM وWhisk بخطط Gemini)، المزايا الكاملة، وحدود الاستخدام. فيه أيضًا مبدّل شهري/سنوي.

**2. بحث تلقائي عن الشعار من لوحة التحكم** — بالأدمن، اكتب اسم الأداة واضغط "بحث تلقائي": الطلب يروح لواجهة `/api/logo-search`، وهي تستعلم من Clearbit Autocomplete (بدون مفتاح API) لجلب الشعار الحقيقي. إذا ما لقت تطابقًا، ترجع تخمين نطاق (`اسم.com` / `.ai` / `.io`) مع خدمة Google Favicons كحل احتياطي، ويظهر عليها وسم "تخمين" للتنبيه بضرورة التحقق البصري قبل الاعتماد. **ملاحظة صريحة:** هذا الجزء ما قدرت أختبره ضد Clearbit الحقيقي من بيئة التطوير هون لأنها بلا اتصال إنترنت خارجي، فقط اختبرت مسار "التخمين الاحتياطي" وضبط شغّال (رجع `openai.com` صح لاسم "OpenAI"). جرّبه فعليًا بعد الرفع للتأكد من جودة نتائج Clearbit نفسها.

**3. محرر خطط كامل باللوحة** — اللوحة كانت لغاية الآن ما فيها تعديل على الأسعار إطلاقًا (فجوة حقيقية بالنسخة السابقة). صار فيها إضافة/حذف/تعديل كل خطة بكل حقولها (شهري، سنوي، لمن تناسب، المزايا، التطبيقات المرفقة، المصدر، تاريخ التحقق).

**4. الكرة الفضائية بالمنتصف** — قسم جديد تحت الهيرو مباشرة (`components/GlobeShowcase.tsx` و`components/Globe3D.tsx`) فيه كرة ثلاثية الأبعاد حقيقية (Three.js + React Three Fiber) تدور، تلمع ببقع عشوائية متحركة، وتتحول كل ٩ ثوانٍ لسطح موجي ثم ترجع كرة. محمّلة بشكل كسول (lazy، بدون SSR) عشان ما تُبطئ أول تحميل للصفحة، ومعطّلة تلقائيًا (تظهر دائرة متوهجة ثابتة بدلها) لو المستخدم مفعّل "تقليل الحركة" (`prefers-reduced-motion`) بجهازه.

> ⚠️ **صراحة بخصوص الكرة:** مكتبتي Three.js وReact Three Fiber يضيفون تقريبًا 200 كيلوبايت إضافية (بعد الضغط) تُحمَّل فقط عند وصول الزائر لهذا القسم تحديدًا، لا عند فتح الصفحة. هذا خفّف الأثر لكنه ما ألغاه — إذا لاحظت بطء فعلي على أجهزة أو اتصالات ضعيفة بعد التجربة الحقيقية، الحل الأسرع هو تقليل تفاصيل الكرة (`sphereGeometry` من 110 إلى 64 مثلًا بملف `Globe3D.tsx`) قبل التفكير بحذفها كليًا.
